Idea

Dictionary defines Usher as ead or guide someone to a place, such as showing them to their seats in a theater or at an event. It can also refer to the act of introducing or marking the beginning of somthing.

Why use a complicated library for managing something trivial such as presentation of HTML elements. Can't a simple tool help us manage this

Implementation

UsherJs handles presentation in a very simple manner. There are specific features available which needs to be initialized, and each feature allows specific functions to control the presentation.

Features

Below are the features implemented by UsherJs.

ViewGroups

ViewGroups control the visibility of elements in a group. Only one item is visible in a single group at a time.
